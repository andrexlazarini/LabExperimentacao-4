# LabExperimentacao-4

Entrega preparada para o Lab04S01: caracterizacao do dataset usado na analise de
impacto de IA em repositorios GitHub.

Arquivos principais:

- `analise_impacto_ia.csv`: dataset original.
- `dados_powerbi/repositorios_caracterizados.csv`: dataset enriquecido para importar
  no Power BI.
- `dados_powerbi/resumo_por_nivel_ia.csv`: resumo por nivel de evidencia de uso de IA.
- `dados_powerbi/distribuicao_ai_score.csv`: distribuicao do score de IA.
- `dados_powerbi/distribuicao_faixa_estrelas.csv`: distribuicao por faixa de estrelas.
- `dados_powerbi/evidencias_ia.csv`: tabela longa para graficos de evidencias de IA.
- `dados_powerbi/top10_repositorios_estrelas.csv`: maiores repositorios por estrelas.
